# КЛЮШКИ RUSSIA — интернет-магазин хоккейной атрибутики

## О проекте
Интернет-магазин хоккейной экипировки и атрибутики. Владелец — новичок в разработке,
поэтому каждое изменение нужно объяснять простыми словами, без лишнего жаргона.
Язык сайта и общения — русский.

## Дизайн
Дерзкий спортивный стиль «лёд и шайба».
- Фон всего сайта — сине-стальной лёд с облачными разводами, царапинами от коньков и
  снежной крошкой. Рисуется скриптом `ice.js` на `<canvas>` (без картинок).
- Шапка и подвал — чёрные (`#07090d`) с синей светящейся линией.
- Главный акцент — синий (`#1e8bff`), как в логотипе: кнопки, активные вкладки, линии.
  Второй акцент — ледяной голубой (`#7fd4ff`) для подсветок. Красный не используем.
- Кнопки и панели со «срезанным уголком», вкладки и метки — с наклоном (skew).
- Заголовки — КАПСОМ, курсив, узкие и жирные; буквы строгие, без «детских» завитков.
- Логотип: файл `images/logo.png` (синий лёд на чёрном). В первом экране он на шайбе;
  шайба влетает сверху при открытии сайта и при нажатии на неё.
  В шапке — текстовый логотип «КЛЮШКИ» + «RUSSIA» в синей наклонной плашке.
- Сайт должен хорошо выглядеть на телефоне (большинство покупателей — с мобильных).

## Технологии (стартовый этап)
- Простой статический сайт: HTML + CSS + немного JavaScript, без сборщиков.
- Страницы: `index.html` (главная), `catalog.html` (каталог), `product.html?id=N` (товар).
- Товары — в `data/products.js` (массив `window.PRODUCTS`). Это JS, а не JSON, чтобы сайт
  работал и при открытии файла двойным щелчком.
- ⚠️ `data/products.js` СОЗДАЁТСЯ АВТОМАТИЧЕСКИ из Excel-таблицы владельца:
  `py tools/import_table.py "путь\к\таблице.xlsx"` — товары правим в таблице, не в файле.
  Python запускается командой `py` (команда `python` на этом компьютере — заглушка Microsoft Store).
  Формат таблицы описан в начале `tools/import_table.py`: A–H восстановленные, L–S реплики,
  U–X прочее (краги, налокотники).
- Правила импорта: «Перо» в пометках → перелом в пере, без пометки → «труба» (подтверждено
  владельцем 2026-11-11); «ВР» → вратарская клюшка, 26"/25" → длина пера; «???» в цене →
  «Цена по запросу»; номер из таблицы хранится в `sku` и показывается на странице товара.
- Разделы и типы клюшек без товаров в каталоге скрываются автоматически.
- Фото — список `photos: [...]`; пока у товаров фото нет (показывается значок раздела).
  Заглушки «ПРИМЕР ФОТО» лежат в `images/placeholders/`.
- `shop.js` — общий код каталога и страницы товара (названия, цены, характеристики, «Заказать»).
- `catalog.js` — блок каталога целиком: сам рисует панель фильтров (раздел, тип клюшки,
  место перелома — только у восстановленных, бренд, хват, «только в наличии», сортировка)
  и карточки внутри `<div id="catalogApp">`. Этот блок стоит И на главной, И на catalog.html —
  правим один раз, меняется везде. На catalog.html (`data-sync-url`) фильтры пишутся в адрес:
  `catalog.html?cat=sticks&type=restored&repair=blade`; на главной адрес не меняется.
- `product.js` — страница товара: галерея (стрелки, миниатюры, свайп, клавиши ← →,
  просмотр на весь экран), характеристики, блок «О ремонте», описание, доставка.
- `script.js` — общий для всех страниц (мобильное меню; шайба и вкладки — только на главной).
- Заказ — через Telegram / звонок (без онлайн-оплаты и корзины). Кнопка «Заказать»
  копирует готовый текст заказа и открывает Telegram.
